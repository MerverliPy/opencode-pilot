# /plan

Create a compact implementation plan for `$ARGUMENTS`.

Required output:

1. Goal and non-goals.
2. Files/symbols likely affected.
3. Agent route.
4. Implementation batches.
5. Verification gates.
6. Risks and open questions.

Use `context-scout` first if affected files are not obvious. Do not edit files.
